# 《她们的日常》

一个无需构建步骤的中文单页自拍影像展览网站。页面使用本地图片，不会加载第三方图库或公开任何真实姓名、联系方式。

## 替换照片

1. 将 9–12 张自拍放入 `assets/photos/`。
2. 首版按顺序命名为 `01.jpg` 至 `12.jpg`；如需少于 12 张，删除 `script.js` 中对应的作品对象。
3. 在 `script.js` 顶部的 `artworks` 数组里修改每张作品的标题、说明、路径和布局。

照片文件缺失时，网站会显示带有“PHOTO PLACEHOLDER”的暖色占位图，因此发布前可逐张替换，不会出现损坏图片。

## 本地预览

直接打开 `index.html` 即可浏览。若要通过本地服务器预览，可在此目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173`。画廊支持点击或触控放大、Esc 关闭、左右方向键切换，并适配手机屏幕。
